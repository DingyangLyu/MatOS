# Contributing to MatOS

Contributions are welcome, especially scientific assets. An asset submission needs a versioned manifest, declared dependencies and permissions, validation evidence and its redistribution license. Reference large datasets, environments and model weights instead of adding them to the repository.

Before sending changes, validate assets with `matos assets validate` and run `bash scripts/matos-user-test-regression.sh`. Report reproducible issues with the source revision, OS/CPU, toolchain versions and sanitized logs.

Contributions are licensed under the same terms as the repository (see LICENSING.md).
