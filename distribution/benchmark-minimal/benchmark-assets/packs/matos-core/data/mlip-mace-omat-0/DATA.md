# MACE-OMAT-0 foundation model

MACE trained on OMat24 (PBE+U, VASP potpaw 54) — among the most accurate open
materials MLIPs on MatBench Discovery, with reduced systematic softening.

- Package: `mace-torch` · License: **ASL** (Academic Software License — check
  restrictions before commercial use/redistribution)
- Loader: `mace_mp(model='<localPath>')`
- Weight: `mace_omat_0/mace-omat-0-medium.model` (github mace-foundations)

Discover local weights via `mcp__matos_asset__mlip_model_catalog {"family":"mace"}`.
See `knowledge:mlip-foundation-model-ecosystem` for when to prefer OMAT-0 vs
MP-0/MPA-0.
