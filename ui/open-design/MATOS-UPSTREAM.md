# MatOS OpenDesign source snapshot

This directory contains the customized OpenDesign frontend and HTTP daemon. The original snapshot came from https://github.com/nexu-io/open-design.git at commit 82117043f4e554fdddc84e8edf41d4c4942ae191 (2026-07-06). Its Apache-2.0 license and attribution are kept in LICENSE.

Conversations run through the native MatOS CLI and the pinned DeepSeek Harness bundle in `vendor/deepseek-harness`. MatOS provides the prompts, roles, scientific assets, sessions, workflows and evolution; OpenDesign provides the project, conversation, file, preview and workflow editor interfaces.
